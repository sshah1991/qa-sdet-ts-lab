## 🚀 Why this repo matters

This repository is more than a code-practice folder. It is a learning path for people who want to grow from writing basic logic into thinking like strong engineers and QA/SDET professionals.

It is designed to help aspiring QA SDETs build value in areas that matter deeply for real-world software engineering and quality work:

- strong programming fundamentals
- structured problem solving
- debugging mindset
- understanding of logic and data flow
- better communication of technical behavior
- readiness for coding interviews and technical discussions

For an aspiring QA SDET, these skills are valuable because quality engineering is not just about checking output — it is about understanding the system, predicting failure points, and reasoning about code behavior with precision.

## 🎯 What this repo aims to build

This lab helps develop:

- TypeScript fundamentals and syntax
- logic-based problem solving
- confidence with arrays, strings, and objects

## ▶️ How to run a file

From the project directory:

```bash
cd "Coding Practice TS/ts-practice"
```

Then run an individual file:

```bash
npx tsx "../src/01_string-basics/splitAndJoins.ts"
```

Run the main file:

```bash
npm run start
```

Run TypeScript validation:

```bash
npm run typecheck
```
